Instrucciones

1. Clona el repositorio.
2. En la terminal, ejecuta: python app.py
3. Abre el enlace que se muestra en la terminal (por defecto es: http://127.0.0.1:5000/)
4. En la barra de direcciones del navegador, añade /factorial/<número> para obtener el factorial del número deseado. Ten en cuenta que este factorial solo debe ser un numero positivo. 
  - Ejemplo: http://127.0.0.1:5000/factorial/6
